# VentureVerse 2026 - Event Landing Page

Landing page for a fictional EDC event (EDC Technical Team Task, Task 01).

## How to run
Download the folder and open `index.html` in any browser. No installation needed.

## Files
- `index.html` - page structure and content
- `style.css` - styling and mobile layout (media query at 700px)
- `script.js` - mobile menu toggle (the bonus feature)

## Sections
Header with navigation, hero with call-to-action, about and highlights (3), schedule (6 items), speakers (3 fictional), footer.
